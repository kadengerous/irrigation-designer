# Irrigation Designer

Проектирование автополива Hunter: чертёж, полив, смета.

Репозиторий: исходный код и все фото каталога Hunter (`public/catalog`).

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:8080`.

## Что внутри

| Папка | Содержимое |
|---|---|
| `src/` | Приложение (React 19, Konva, Zustand) |
| `public/catalog/` | Фото дождевателей, сопел и корпусов Hunter |
| `scripts/` | Сборка, тесты, упаковка исходника |
| `server/` | Серверные плагины |

`node_modules` в репозиторий не входит — ставится через `npm install`.
